# HomeSense-AQ-System-Design[HomeSense-AQ_System_Requirements_and_Block_Diagram.pdf](https://github.com/user-attachments/files/33757774/HomeSense-AQ_System_Requirements_and_Block_Diagram.pdf)

HomeSense-AQ: a smart home air-quality monitor design . Covers requirements, hardware block diagram, software architecture and design justification for an STM32L476RG + ESP32-C3 device that measures CO2, VOC, temperature, humidity and light, alerts locally and publishes data over MQTT/TLS.
